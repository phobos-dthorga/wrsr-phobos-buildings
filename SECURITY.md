# Security and privacy

Use GitHub private vulnerability reporting when available for sensitive reports.
Never publish credentials, populated secret fields, player saves or personal paths
in an issue. For ordinary research discrepancies, use an issue with sanitised evidence.

The founding repository contains documentation, planning manifests and a standard-library
repository checker. It does not install mods, download modelling tools, run a game,
modify saves or implement a runtime plugin. Any future tool doing those things needs
an explicit documented scope and validation of its target paths.
